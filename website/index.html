Up and running in a minute.

Sora is a portable app. There is no installer.

Download.

Get the installer (.msi), the portable .exe or the Mac .dmg from the latest release on GitHub.

Keep it in a folder.

Move it to a folder you keep, such as Documents or a Tools folder. Not Program Files.

Run it.

Double-click Sora.exe. The notch appears at the top of your screen. Click it to open the panel.

Windows protected your PC?

The download is not code-signed yet, so SmartScreen may warn the first time you run it. Click More info, then Run anyway. The release page lists the SHA-256 checksum if you want to verify the file.

Requires Windows 10 (version 1903) or Windows 11, x64, and the Microsoft WebView2 Runtime (included in Windows 11).

Questions? Answers.

Is Sora free?

Yes. Sora is free and open source under the GPL-3.0 license. There are no ads and no paid tier.

Does it work on Windows 10?

Yes, on Windows 10 version 1903 or later, and on Windows 11 (x64). It needs the Microsoft WebView2 Runtime, which is already included in Windows 11.

Why does Windows show a SmartScreen warning?

The GitHub download is not code-signed yet. Click More info, then Run anyway. The Microsoft Store version will be signed and update automatically.

How do I hide Sora?

Press Ctrl + Alt + Space, or use the tray icon menu. You can change the shortcut in Settings. During full-screen apps and games Sora shrinks into a capsule by itself.

What do I need on my phone to receive files?

The LocalSend app on your phone, or Quick Share on Android. Your phone and PC need to be on the same Wi-Fi network.

Which music apps are supported?

Any player or browser that shows up in the Windows media controls (the media box in the volume flyout).

How do I remove Sora?

Turn off Start with Windows in Settings if you enabled it, quit Sora from the tray icon menu, then delete Sora.exe. To remove your settings and events too, delete its app data folder.
